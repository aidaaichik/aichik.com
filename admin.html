Catalogue tool

Add a new artwork

Fill this once. The tool prepares the artwork record and a web-ready copy of your image for GitHub.

After clicking “Prepare artwork files”
  1. Two files download: the artwork image and a small .md artwork record.
  2. In GitHub, upload the image into assets/artworks/.
  3. Upload the .md file into _artworks/.
  4. Commit the changes. GitHub Pages automatically creates the gallery entry and permanent /art/title/ page.

No HTML editing is required. Price and dimensions can be left blank and added later.
